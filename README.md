# Portfolio — Marvin Gustavo Rodas Monzón

Portfolio personal desarrollado para presentar mi experiencia, proyectos y tecnologías como **Full Stack Developer**.

**Portfolio:** https://porfolio.dev/

---

## Tecnologías

Este proyecto está desarrollado utilizando:

* **Astro**
* **JavaScript**
* **Tailwind CSS**
* **HTML5**
* **CSS3**

También utiliza componentes propios desarrollados con **Astro** y una estructura orientada a mantener el proyecto simple, responsive y fácil de mantener.

---

## Sobre el proyecto

El portfolio presenta diferentes secciones relacionadas con mi perfil profesional:

* Presentación personal
* Experiencia profesional
* Proyectos
* Tecnologías y habilidades
* Información de contacto
* Enlaces a GitHub y LinkedIn
* Soporte para tema claro y oscuro
* Diseño responsive para escritorio, tablet y dispositivos móviles
* Filtros de proyectos por perfil y tecnologías
